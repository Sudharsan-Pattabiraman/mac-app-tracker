Popover size and density

Zinc, monochrome, 10px radius and JetBrains Mono, drawn at real size (1 CSS px = 1 macOS point). Each popover has a fixed 560pt height and scrolls the app list inside it. Compact rows are about 32pt tall; comfortable rows are about 44pt. Notice how many apps fit before scrolling, and where long names start to truncate.
