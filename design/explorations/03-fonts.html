Font options

The same zinc popover with a 10px radius, set in eight font setups. The first three use JetBrains Mono. Durations use each setup's number font with tabular figures, so digits line up. SF Pro and SF Mono only render on Apple devices. On Windows, Android or Linux those cards fall back to a generic system font, so open this page on your Mac to judge them.

Your device doesn't have SF Pro, so cards 2, 4, 7 and 8 are not showing the real font.
