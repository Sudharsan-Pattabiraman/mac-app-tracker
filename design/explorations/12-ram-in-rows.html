RAM in each app row

Seven ways to show live memory per app in the 380pt popover, all with the same 24h data. RAM is the current footprint, including helper processes, read only while the popover is open. Apps that aren't running (Figma here) show a dash. Variants marked "hot" draw apps using 2 GB or more in full foreground ink, and everything else in muted gray, so heavy apps stand out without adding color.
